# Anime 360° Analytics & Insights Dashboard

## 📊 Project Overview

An interactive Power BI dashboard created to analyze anime data and
identify insights related to ratings, popularity, genres, episodes,
and audience engagement.

## 🛠️ Tools & Technologies

- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Dashboard Insights

- Anime popularity analysis
- Rating and score analysis
- Genre-wise analysis
- Episode count analysis
- Top-rated anime
- Audience/member engagement
- Interactive filtering and visualization

## 📁 Project File

The Power BI dashboard is available in this repository:

`Project__@2.pbix`

## 🎯 Objective

To transform raw anime data into meaningful visual insights through
an interactive Power BI dashboard.
